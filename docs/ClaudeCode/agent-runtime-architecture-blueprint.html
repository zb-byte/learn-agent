横切能力与可恢复状态
Context, extension, persistence and recovery rails

Context Builder

context.ts 生成 git status、CLAUDE.md、日期和运行上下文；它是模型输入边界，不是权限边界。

Compaction

autoCompact、microcompact、context collapse 管上下文窗口，输出 compact boundary。

Memory

relevant memory prefetch、nested memory、session memory 是上下文补充机制，不等同于 prompt cache。

Extensions

MCP、Plugin、Skill、AgentTool 聚合外部能力；AgentTool 会递归进入独立 query loop。

Transcript / Resume

sessionStorage 持久化消息链、file history、agent sidechain，支持 resume 与 fork-session。

Reading rule: 主链路从左到右，工具结果回到 Agent Loop。底部能力不是顺序层，而是会被入口、编排、query loop 和工具执行共同调用的横切轨道。

Architecture rule: 不再单独设置重复的“运行模式层”；模式是入口适配与 ToolUseContext 的属性。也不把 UI 状态、turn state、session singleton 和恢复状态混成一个“状态层”。
