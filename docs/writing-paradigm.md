## 核心写作原则

### 原则1：三层递进结构

```
概念层（What）→ 机制层（How）→ 源码层（Where）
```

**实施方法：**

| 层级 | 内容 | 表达方式 |
|------|------|---------|
| 概念层 | 是什么、为什么需要 | 类比、生活化语言 |
| 机制层 | 怎么做、工作原理 | 流程图、对比表格 |
| 源码层 | 在哪里实现、关键代码 | 源码片段、文件行号 |

**示例：**

```markdown
### 1.1 delegate_task 是什么？（概念层）

简单来说，`delegate_task` 就像是"项目经理把任务分配给团队成员"：
- 父Agent（项目经理）遇到复杂任务时，可以创建子Agent（团队成员）
- 子Agent独立工作，有自己的思考过程和工具
- 完成后，子Agent把结果汇报给父Agent

### 1.2 执行流程图（机制层）

```
用户提问
  ↓
父Agent调用 delegate_task
  ↓
创建子Agent
  ↓
返回结果
```

### 1.3 源码追踪路径（源码层）

1. `toolsets.py` - 定义delegation toolset
2. `tools/delegate_tool.py:1918` - delegate_task()函数
3. `tools/delegate_tool.py:870` - _build_child_agent()
```

### 原则2：源码锚点法则

**每个技术断言必须有源码证据**

**标准格式：**

```markdown
**源码证据：**

​```python
# 文件路径:起始行-结束行
[关键代码片段]
​```
```

**关键点：**
- 必须标注**文件路径 + 行号范围**
- 代码片段要**精简**，只保留核心逻辑
- 用注释说明**为什么引用这段代码**

**示例：**

```markdown
**为什么子Agent不能使用clarify工具？**

**源码证据：**

​```python
# tools/delegate_tool.py:44-53
DELEGATE_BLOCKED_TOOLS = frozenset([
    "delegate_task",  # no recursive delegation
    "clarify",        # no user interaction
    "memory",         # no writes to shared MEMORY.md
    "send_message",   # no cross-platform side effects
    "execute_code",   # children should reason step-by-step
])
​```
```

### 原则3：类比优先原则

**抽象概念先用生活化类比建立直觉**

**常用类比模板：**

| 技术概念 | 类比对象 | 效果 |
|---------|---------|------|
| Agent | 团队成员 | 理解角色和职责 |
| Context Window | 工作记忆容量 | 理解限制 |
| Memory System | 笔记本 | 理解持久化 |
| Delegate Task | 项目经理分配任务 | 理解工作流 |

**示例：**

```markdown
**Hermes如何"学习"？**

Hermes不会修改大模型的参数（不是训练），而是把经验保存到外部存储。

**类比：**
- 大模型 = 你的大脑（固定能力）
- 记忆系统 = 你的笔记本（可以随时查阅和更新）
```

### 原则4：表格驱动说明

**用表格对比差异/列举特性**

**适用场景：**
- 对比不同方案
- 列举配置项
- 说明工作流程
- FAQ问答

**标准表格格式：**

```markdown
| 对比维度 | 方案A | 方案B | 设计原因 |
|---------|------|------|---------|
| 执行模型 | 单次函数调用 | 多轮Agent循环 | ... |
| 上下文 | 共享父上下文 | 独立上下文 | ... |
```

## 可视化技巧

### 1. ASCII流程图

**简单线性流程：**

```
用户提问
  ↓
父Agent思考
  ↓
调用 delegate_task
  ↓
创建子Agent
  ↓
子Agent工作
  ↓
返回结果
  ↓
父Agent综合
```

**分支流程：**

```
任务到达
  ↓
判断任务类型
  ├── 简单任务 → 直接执行 → 返回结果
  └── 复杂任务 → 分解子任务 → 并行执行 → 汇总结果
```

**循环流程：**

```
┌─────────────┐
│ Agent工作   │
└──────┬──────┘
       ↓
   调用工具
       ↓
   ┌─────────┐
   │完成？   │
   └────┬────┘
        ├── 否 → 继续循环
        └── 是 → 返回结果
```

### 2. 树形结构

**目录结构：**

```
~/.hermes/
  ├── memories/
  │   ├── MEMORY.md
  │   └── USER.md
  ├── skills/
  │   └── skill-name/
  │       ├── SKILL.md
  │       └── references/
  └── sessions.db
```

**配置继承链：**

```
子Agent继承配置：
├─ model: 模型名称（可覆盖）
├─ provider: API提供商（可覆盖）
├─ api_key: API密钥（可覆盖）
└─ toolsets: 工具集（过滤后继承）

子Agent独立配置：
├─ system_prompt: 根据goal生成
├─ _subagent_id: 唯一标识
└─ _delegate_depth: 嵌套深度
```

### 3. 对比框图

```
┌─────────────────┐     ┌─────────────────┐
│   普通工具调用   │     │  delegate_task   │
├─────────────────┤     ├─────────────────┤
│ 共享父上下文     │     │ 独立子上下文     │
│ 单次函数执行     │     │ 多轮Agent循环    │
│ 无状态          │     │ 有独立状态       │
└─────────────────┘     └─────────────────┘
```

### 4. 表格图表

**使用 Markdown 表格展示矩阵数据：**

| 记忆类型 | 保存内容 | 使用时机 | 存储位置 |
|---------|---------|---------|---------|
| Declarative | 用户偏好、环境事实 | 每次对话加载 | MEMORY.md |
| Episodic | 过去对话、工具调用 | 按需搜索 | Session DB |
| Procedural | 任务方法、步骤 | 执行类似任务 | skills/ |
| External | 外部服务召回 | 每轮对话前 | 第三方服务 |

## 语言风格规范

### 1. 标题命名规范

| 级别 | 格式 | 示例 |
|------|------|------|
| 一级标题 | 系统名 + 主题 + "详解" | `# Hermes-Agent 运行时原理详解` |
| 二级标题 | 核心机制名称 | `## 1. 多Agent机制：delegate_task` |
| 三级标题 | 具体子功能 | `### 1.1 核心概念` |
| 四级标题 | 细节说明 | `#### 1.1.1 什么是delegate_task` |

### 2. 段落组织结构

**标准三段式：**

```markdown
[首段] 一句话说明"是什么"
  ↓
[中段] 用类比/表格/流程图说明"怎么做"
  ↓
[尾段] 用源码证据证明"真实性"
```

**示例：**

```markdown
### 1.1 核心概念

**delegate_task是什么？**

简单来说，就是"项目经理分配任务给团队成员"。[首段]

关键特点：
| 特点 | 说明 |
|------|------|
| 同步执行 | 父Agent等待子Agent完成 |
| 独立运行时 | 子Agent有自己的上下文 |

**源码证据：**
​```python
# tools/delegate_tool.py:1-5
"""
Each child gets a fresh conversation with isolated context.
"""
​``` [尾段]
```

### 3. 术语处理规范

**首次出现：**

```markdown
**Agent**（智能代理）：一个完整的AI助手实例，包含对话循环、工具集、记忆等能力。
```

**后续使用：**
- 直接使用术语，不加定义
- 必要时可用括号注明原文

**缩写处理：**

```markdown
首次使用：Prompt Caching（提示词缓存）
后续使用：Prompt Cache
```

### 4. 代码引用规范

**标准格式：**

```python
# 文件路径:起始行-结束行
[精简的关键代码]

# 用注释说明关键点
关键逻辑说明

# 省略号表示跳过部分
# ... [省略中间代码]

另一段关键代码
```

**示例：**

```python
# tools/delegate_tool.py:920-922
# 生成子Agent唯一ID
subagent_id = f"sa-{task_index}-{_uuid.uuid4().hex[:8]}"
parent_subagent_id = getattr(parent_agent, "_subagent_id", None)

# tools/delegate_tool.py:1021-1024
# 模型配置继承逻辑（优先级：参数 > 配置 > 父Agent）
effective_model = model or parent_agent.model
effective_provider = override_provider or getattr(parent_agent, "provider", None)
```
