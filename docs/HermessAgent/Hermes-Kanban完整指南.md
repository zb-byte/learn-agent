# Hermes Kanban 完整指南

## 1. 概述

Hermes Kanban 是一个基于 SQLite 的持久化任务看板系统，专为多智能体协作设计。它允许多个命名的 Hermes 配置文件（profiles）在共享的任务队列上协作，而无需脆弱的进程内子智能体集群。

### 核心特性

- **持久化存储**：所有任务、评论、事件存储在 `~/.hermes/kanban.db` (SQLite + WAL 模式)
- **多看板架构**：支持多个独立看板，每个看板有独立的数据库和工作空间
- **双接口设计**：
  - **CLI 接口** (`hermes kanban ...`)：供人类和脚本使用
  - **工具接口** (`kanban_*` 工具集)：供智能体工作者使用
- **网关内嵌调度器**：默认运行在 gateway 进程内，60秒轮询间隔
- **原子化任务声明**：每个任务是 SQLite 中的一行，每次交接是任何配置文件都能读写的一行
- **完整审计追踪**：所有状态转换记录在 `task_events` 表中，永久保存

```
       │                              │ kanban_block()
       ▼                              ▼
   ┌─────────────────────────────────────────┐
   │         kanban_db 层 (Python)           │
   │    (统一的读写接口，两侧调用相同代码)      │
   └──────────────┬──────────────────────────┘
                  │
                  ▼
   ┌─────────────────────────────────────────┐
   │      ~/.hermes/kanban.db (SQLite)       │
   │                                         │
   │  • tasks          (任务主表)            │
   │  • task_runs      (运行历史)            │
   │  • task_events    (事件日志)            │
   │  • task_links     (依赖关系)            │
   │  • task_comments  (评论)                │
   └─────────────────────────────────────────┘
                  ▲
                  │
   ┌──────────────┴──────────────────────────┐
   │      Dispatcher (网关内嵌)               │
   │                                         │
   │  每 60 秒执行一次：                       │
   │  1. 回收过期声明                         │
   │  2. 检测崩溃的工作者                      │
   │  3. 提升 ready 任务                      │
   │  4. 原子化声明并生成工作者                 │
   └─────────────────────────────────────────┘
```
