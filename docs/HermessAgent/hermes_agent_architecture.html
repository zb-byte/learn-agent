Hermes Agent 系统架构
Architecture Overview / v0.14.0
Layer 1: 用户接口层 (User Interface Layer)
CLI (cli.py)
交互式命令行界面，基于 Rich 和 prompt_toolkit
  • • 命令解析与分发 (process_command)
  • • 自动补全 (SlashCommandCompleter)
  • • 会话管理 (session_id, history)
  • • 皮肤引擎 (skin_engine)
  • • KawaiiSpinner 动画显示
TUI (ui-tui/)
基于 Ink (React) 的终端 UI
  • • entry.tsx, app.tsx
  • • gatewayClient.ts (JSON-RPC)
  • • 组件化界面 (components/)
  • • 实时流式输出
Gateway (gateway/)
多平台消息网关
  • • run.py (主网关逻辑)
  • • session.py (会话管理)
  • • platforms/ (Telegram, Discord, Slack...)
  • • 异步消息处理
  • • 平台适配器模式
Layer 2: 核心 Agent 层 (Core Agent Layer)
AIAgent (run_agent.py)
Agent 主类，管理整个对话生命周期
  • • __init__ (60+ 参数初始化)
  • • run_conversation() (主循环)
  • • chat() (简化接口)
  • • _build_system_prompt()
  • • 会话状态管理
agent_init.py
Agent 初始化逻辑 (从 run_agent.py 提取)
  • • init_agent() (1400+ 行初始化)
  • • 提供商自动检测
  • • 凭证解析
  • • 上下文引擎引导
  • • 工具集验证
conversation_loop.py
对话循环核心逻辑 (3900+ 行)
  • • run_conversation() (主循环)
  • • 模型调用与重试
  • • 工具调度
  • • 错误处理与降级
  • • 上下文压缩触发
  • • 预算跟踪
agent_runtime_helpers.py
运行时辅助函数
  • • 消息格式转换
  • • 流式响应处理
  • • 工具调用解析
  • • 回调触发
Layer 3: 模型适配层 (Model Adapter Layer)
anthropic_adapter.py
Anthropic Messages API 适配器
  • • OpenAI → Anthropic 格式转换
  • • OAuth / API Key 认证
  • • 思考模式配置 (adaptive/extended)
  • • 缓存控制 (cache_control)
  • • max_tokens 自动计算
gemini_native_adapter.py
Google Gemini 原生 API 适配器
  • • 消息格式转换
  • • 工具调用映射
  • • 流式响应处理
bedrock_adapter.py
AWS Bedrock 适配器
  • • boto3 客户端管理
  • • 凭证链解析
  • • 消息格式适配
codex_responses_adapter.py
Codex Responses API 适配器
  • • 响应格式转换
  • • 工具调用 ID 生成
  • • 消息摘要
Layer 4: 工具系统层 (Tool System Layer)
model_tools.py
工具编排层，公共 API
  • • get_tool_definitions()
  • • handle_function_call()
  • • check_toolset_requirements()
  • • 异步桥接 (_run_async)
  • • 工具集解析
tools/registry.py
工具注册中心
  • • register() (工具注册)
  • • discover_builtin_tools()
  • • ToolEntry 元数据
  • • check_fn TTL 缓存
  • • 动态 schema 覆盖
tools/*.py
80+ 工具实现
  • • terminal_tool.py (命令执行)
  • • file_tools.py (文件操作)
  • • browser_tool.py (浏览器自动化)
  • • delegate_tool.py (子 Agent)
  • • 每个工具自注册到 registry
toolsets.py
工具集定义
  • • _HERMES_CORE_TOOLS 列表
  • • resolve_toolset()
  • • validate_toolset()
  • • 组合工具集 (research, development...)
Layer 5: 记忆与上下文层 (Memory & Context Layer)
memory_manager.py
记忆管理器，协调多个记忆提供商
  • • MemoryManager 类
  • • add_provider() (注册提供商)
  • • prefetch_all() (预取记忆)
  • • sync_all() (同步记忆)
  • • StreamingContextScrubber (流式清理)
context_compressor.py
自动上下文窗口压缩
  • • ContextCompressor 类
  • • compress_if_needed()
  • • 保护头尾上下文
  • • 工具输出修剪
  • • LLM 摘要生成
  • • 迭代摘要更新
prompt_builder.py
系统提示词组装
  • • build_system_prompt()
  • • build_skills_system_prompt()
  • • build_context_files_prompt()
  • • 扫描 HERMES.md / AGENTS.md
  • • 注入检测 (威胁模式扫描)
prompt_caching.py
Anthropic 提示词缓存
  • • apply_anthropic_cache_control()
  • • 缓存点标记
  • • 5 分钟 TTL 管理
Layer 6: 支持系统层 (Support Systems Layer)
credential_pool.py
凭证池管理
  • • CredentialPool 类
  • • 多凭证轮换
  • • 速率限制跟踪
  • • 凭证健康检查
error_classifier.py
API 错误分类器
  • • classify_api_error()
  • • FailoverReason 枚举
  • • 重试策略决策
  • • 降级触发
retry_utils.py
重试工具
  • • jittered_backoff()
  • • 指数退避
  • • 抖动算法
rate_limit_tracker.py
速率限制跟踪
  • • 每提供商速率跟踪
  • • 冷却时间管理
  • • 自动恢复
iteration_budget.py
迭代预算管理
  • • IterationBudget 类
  • • 父子预算共享
  • • 预算耗尽检测
display.py
显示与 UI 辅助
  • • KawaiiSpinner (动画 spinner)
  • • build_tool_preview()
  • • get_cute_tool_message()
  • • 工具失败检测
Layer 7: 数据持久化层 (Data Persistence Layer)
hermes_state.py
会话数据库 (SQLite + FTS5)
  • • SessionDB 类
  • • create_session() / get_session()
  • • update_system_prompt()
  • • FTS5 全文搜索
  • • 会话历史持久化
trajectory_compressor.py
轨迹压缩与保存
  • • 对话轨迹格式化
  • • JSONL 保存
  • • 成功/失败轨迹分离
checkpoint_manager.py
检查点管理
  • • 会话快照
  • • 回滚支持
  • • 检查点恢复
